# Kvalitetskontrol & Bånd-label — udgivelser

Byggede udgaver af to små, uafhængige Windows-programmer.

* `EgenKontrol.exe` + `version.json` — kvalitetskontrol
* `BaandLabel.exe` + `baandlabel-version.json` — bånd-label

Hvert program henter selv sin egen version.json for at se, om der er
en nyere udgave. Derfor er siden offentlig: så det kan ske uden
nogen form for nøgle i nogen af programfilerne.

Der gemmes kun den nyeste udgave af hver. Kildekoden ligger et andet sted.
